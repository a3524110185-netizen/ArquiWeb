# Anexo A — Capturas de Pantalla Recomendadas

Lista consolidada de las capturas sugeridas a lo largo del manual, agrupadas por módulo, para que quien realice la sesión de capturas tenga una checklist única. Se recomienda usar una cuenta de cada rol (administrador, gerente, supervisor, ingeniero, superadmin) para las capturas marcadas con "(rol)".

## 0. Introducción
- [ ] Pantalla de login vacía.
- [ ] Pantalla de login con mensaje de error.
- [ ] Dashboard inmediatamente después de iniciar sesión (uno por rol).

## 1. Navegación general
- [ ] Sidebar completo (administrador).
- [ ] Sidebar de un rol de campo (supervisor o ingeniero).
- [ ] Sidebar colapsado.
- [ ] Header con "Cambiar de empresa" desplegado.
- [ ] Modal "Seleccionar Empresa" con varias tarjetas.
- [ ] Estado "Sin empresa" en el Header.

## 2. Proyectos
- [ ] Lista de proyectos con chips de estado.
- [ ] Buscador con resultados filtrados.
- [ ] Formulario "Crear Proyecto" con el mapa visible.
- [ ] Formulario de edición con el selector de Estado.
- [ ] Modal "Gestionar Equipo de Proyecto".
- [ ] Detalle completo de un proyecto (las 5 secciones).
- [ ] Tabla "Historial de Avances" con botones Aprobar/Rechazar (sesión gerente).

## 3. Incidencias
- [ ] Lista de incidencias con pestañas y filtros.
- [ ] Vista "Mis Incidencias" (ingeniero) vs. "Incidencias Globales" (gerente).
- [ ] Botones "Iniciar Atención" / "Marcar como Resuelta" (ingeniero).
- [ ] Selector de Estado con las 4 opciones (gerente/administrador).
- [ ] Diálogo de comentario obligatorio al resolver/cerrar.
- [ ] Sección "Comentarios" con historial.

## 4. Reportes diarios
- [ ] Lista con selector de proyecto y tarjetas KPI.
- [ ] Fila expandida con descripción y fotos.
- [ ] Íconos de aprobar/rechazar en una fila pendiente.
- [ ] Modal "Rechazar Reporte" con motivo.
- [ ] Detalle de un reporte aprobado, con fotos.
- [ ] Detalle de un reporte rechazado, con motivo visible.

## 5. Galería de evidencias
- [ ] Cuadrícula completa de la galería.
- [ ] Selector "Filtrar por Proyecto" desplegado.
- [ ] Miniatura con superposición de información.
- [ ] Visor de pantalla completa.

## 6. Asistencia
- [ ] Pantalla de Asistencia en cada uno de los 4 estados.
- [ ] Sección "Timeline de hoy" con los 4 pasos completados.

## 7. Usuarios
- [ ] Lista de usuarios con filtros de rol/estado.
- [ ] Modal "Nuevo Usuario".
- [ ] Modal "Editar Usuario" con "Nueva contraseña (opcional)".
- [ ] Diálogo "Desactivar usuario".
- [ ] Fila de usuario inactivo con ícono de reactivar.

## 8. Horarios y Control Horario
- [ ] Tabla de "Configuración de Horario Laboral" (administrador).
- [ ] Misma pantalla en modo "Solo lectura".
- [ ] Control Horario con todos los filtros (administrador).
- [ ] Control Horario sin filtro de Usuario ni exportación (supervisor/ingeniero).
- [ ] Tabla de resultados con estados Completo/Incompleto/Falta.

## 9. Reporte de Horas
- [ ] Pantalla con las 3 tarjetas KPI y tabla resumen.
- [ ] Fila expandida con desglose diario.

## 10. Días No Laborales
- [ ] Vista de calendario mensual con días resaltados.
- [ ] Tabla de días no laborales.
- [ ] Modal "Registrar Día No Laboral".
- [ ] Diálogo "Eliminar registro".

## 11. Catálogos
- [ ] Lista de materiales con insignias de stock.
- [ ] Formulario "Nuevo Material".
- [ ] Modal "Nuevo Proveedor".
- [ ] Directorio de clientes.

## 12. Comercial
- [ ] Tabla "Control de Inventario" con "Solo bajo stock" activado.
- [ ] Modal "Registrar Movimiento".
- [ ] Formulario "Nueva Cotización" con partidas y totales.
- [ ] Detalle de cotización con "Convertir a Venta" visible.
- [ ] Vista previa de impresión (PDF) de una cotización.
- [ ] Lista de ventas con filtros.
- [ ] Formulario "Nueva Venta Directa" con buscador de materiales.
- [ ] Detalle de venta generada desde una cotización.
- [ ] Formulario "Nuevo Pedido".
- [ ] Modal "Cambiar estado del pedido".

## 13. Gastos de Obra
- [ ] Lista de gastos con filtros aplicados.
- [ ] Formulario "Nuevo Gasto" con comprobante cargado.
- [ ] Formulario de edición con "Ver comprobante actual" / "Reemplazar".
- [ ] Gráficas "Gastos por Categoría" y "Gastos por Proyecto".

## 14. Dashboard Ejecutivo
- [ ] Vista completa con las 6 tarjetas KPI.
- [ ] Gráfica de líneas "Ventas — Últimos 6 Meses".
- [ ] Gráfica de barras "Proyectos por Estado".
- [ ] Tarjetas "Últimas Ventas" y "Últimas Incidencias".

## 15. Dashboard Superadmin
- [ ] Vista completa con 4 KPIs y ambas gráficas.
- [ ] Lista de empresas con filtro de estado.
- [ ] Formulario "Nueva Empresa".
- [ ] Detalle de empresa con "Usuarios de la Empresa" y "Asignar Administrador".
- [ ] Lista "Usuarios Globales" con filtro por empresa.
- [ ] Modal "Cambiar Rol de Usuario".
