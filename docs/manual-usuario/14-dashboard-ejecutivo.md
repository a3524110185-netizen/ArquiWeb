# 14. Dashboard Ejecutivo

**Rol(es):** Administrador y Gerente.
**Ubicación:** `Ruta: /dashboard-ejecutivo` — menú "Dashboard Ejecutivo".

## Ver KPIs globales

### Pasos
1. Ir a "Dashboard Ejecutivo" en el menú lateral.
2. Revisar las 6 tarjetas KPI (cada una es un enlace directo al módulo correspondiente):

| KPI | Descripción | Enlace a |
|---|---|---|
| Ventas del Mes | Total facturado este mes | Ventas |
| Incidencias Pendientes | Abiertas o en progreso | Incidencias |
| Materiales Stock Bajo | Requieren reabastecimiento | Inventario |
| Total Empleados | Usuarios activos | Usuarios |
| Proyectos Activos | En ejecución / total | Proyectos |
| Avance Promedio | Físico de proyectos | Proyectos |

3. Usar el botón **"Actualizar"** para refrescar los datos manualmente.

### Capturas de pantalla sugeridas
- Vista completa del Dashboard Ejecutivo con las 6 tarjetas KPI.

### Resultado esperado
El usuario obtiene una fotografía rápida del estado del negocio y puede navegar directamente al módulo detrás de cada indicador.

## Ver actividad reciente (ventas, incidencias)

**Ubicación:** Parte inferior del Dashboard Ejecutivo, dos tarjetas lado a lado.

### Contenido
- **"Últimas Ventas"**: las 5 ventas más recientes (folio, cliente, fecha, total), cada una enlaza a su detalle. Enlace **"Ver todas"** hacia el módulo de Ventas.
- **"Últimas Incidencias"**: las 5 incidencias más recientes (con insignia de estado por color), cada una enlaza a su detalle. Enlace **"Ver todas"** hacia el módulo de Incidencias.

### Capturas de pantalla sugeridas
- Tarjetas "Últimas Ventas" y "Últimas Incidencias" con varios registros cada una.

### Resultado esperado
Permite detectar rápidamente movimientos recientes relevantes sin tener que entrar a cada módulo por separado.
